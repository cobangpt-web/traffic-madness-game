## 성능 검증

자동화 브라우저의 빈 페이지 `requestAnimationFrame` 기준은 50.47fps였고, 게임 플레이 중에는 50.29fps였다. 테스트 환경의 표시 주기 대비 약 99.6%를 유지했으며 프레임 드롭 징후가 없었다.

## 수정 후 재검증한 사항

1. `src/rendering/assets.ts`: 흙 모서리가 포함된 잔디 타일을 순수 잔디 타일로 교체해 반복 무늬를 제거했다.
2. `src/ui/DomView.ts`: 숨기는 오버레이에 `inert`를 적용하고 포커스를 해제해 `aria-hidden` 경고를 제거했다.
3. `src/rendering/Renderer.ts`: 매 프레임 레이아웃 측정을 제거하고 `ResizeObserver` 기반으로 변경했다.
